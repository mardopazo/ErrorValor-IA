4. 🔬 Análisis de Causa Raíz (Los 5 ¿Por qué?)

Metodología para llegar al problema sistémico profundo.
1. ¿Por qué fallaron los pagos? -Porque la base de datos no respondió a tiempo.-
2. ¿Por qué no respondió a tiempo? -Porque el parámetro de timeout se redujo drásticamente.-
3. ¿Por qué se redujo drásticamente? -Porque se unificó la configuración con el entorno de testing.-
4. ¿Por qué se unificó sin validar el impacto? -Porque el proceso de revisión de variables de entorno es manual y no está documentado en el pipeline.-
5. ¿Por qué es manual? (Causa raíz) -Porque no contamos con una herramienta de gestión de configuración automatizada que valide límites según el entorno.-

5. 🛑 Factores Contribuyentes (El Entorno)

¿Qué elementos del entorno o las herramientas facilitaron que el error ocurriera?
* Falta de visibilidad: El sistema de monitoreo no reflejó la saturación de conexiones de inmediato.
* Documentación desactualizada: El manual de despliegue no mencionaba las dependencias de esa variable.
